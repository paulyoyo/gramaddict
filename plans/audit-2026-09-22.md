## 2. Decisions for Paul

1. **B1, platform risk.** GramAddict automates the Instagram app through the UI, not the official API. Ban risk is inherent. Do you accept that risk for this account, as you have so far? (No code change proposed.)
2. **Behavior change: PMs to private/empty accounts.** `interaction.py:144` never calls `can_pm_to_private_or_empty`, so the check is always true. Today private and empty accounts DO get PMs and greetings. If we fix it, they stop unless `pm_to_private_or_empty: true` is in `filters.yml`. Should they keep getting PMs? If yes, fix the call and add the key to your filters.
3. **Behavior change: `skip_if_public`.** `filter.py:295` is inverted: with `skip_if_public: true` it skips private accounts and keeps public ones. Is `skip_if_public` set in any of your configs? Fixing it will change who gets targeted.
4. **Upstream sync.** Do you still plan to merge upstream GramAddict updates? If yes, keep refactors below minimal (no global-config rewrite, no view-class reshuffle).
5. **Global config via `load_config` (P1/P4, M).** Five modules mutate module globals. It only hurts for multi-account-in-one-process or unit tests. Worth doing? My recommendation: no, unless you need one of those.
6. **Headless runs.** `bot_flow.py:184` waits on `input()` on an untested IG version unless `allow-untested-ig-version: true` is set. Does the bot run unattended (launchd or cron)? If so, set that key in config. No code change needed.
7. **Tensions (rubric simplicity vs. SOLID).** Recommendation for all three: leave as is.
   - Page-object view classes vs. plain functions in `views.py`.
   - Flat `handle_sources.py` vs. one handler class per source.
   - Direct JSON storage vs. a repository interface.

### Paul's answers (2026-09-22)

1. B1: accepted; no official API option. Keep UI automation.
2. Keep PMs to private/empty accounts → fix the `()` but make `can_pm_to_private_or_empty` default to True when the key is absent (keeps today's behavior, `false` now actually works).
3. `skip_if_public` not used → fix freely.
4. No upstream sync → refactors allowed.
5. Skip the global-config refactor.
6. Untested IG version must stop the bot and notify Paul (Slack), not wait on `input()`. Also fix version compare: `tuple(str.split("."))` compares strings ("9" > "10").
7. Tensions resolved in favor of SOLID → new later batches: source handler classes for `handle_sources.py`, a storage interface, keep page-object views.

## 3. Backlog

### Batch 1 — Don't lose state files (data loss) · S
- Goal: a failed or crashing persist never deletes user/session history, and a corrupt file never exits with code 0.
- Findings: B5 `persistent_list.py:40` `os.remove` before the atomic write (ACCEPTED, critical); P3 `sys.exit(0)` on corrupt JSON in `persistent_list.py:39`, `storage.py:57,70,83` (ACCEPTED, major); B5 `Storage.__init__` returns half-built when username is None, `storage.py:34-38` (ACCEPTED, minor).
- Files: `GramAddict/core/persistent_list.py`, `GramAddict/core/storage.py`.
- Tests: one pytest for `PersistentList.persist`: an item without `id` raises AND the existing file is still there. Smoke: corrupt `sessions.json` gives a non-zero exit with a clear message.

### Batch 2 — Filter and PM correctness · S (blocked on decisions 2 and 3)
- Goal: filters do what `filters.yml` says.
- Findings: `filter.py:295` inverted `skip_if_public` (ACCEPTED, critical); `interaction.py:144` missing `()` on `can_pm_to_private_or_empty` (ACCEPTED, critical); `views.py:846` `post_owner_obj.exists` missing `()`, which disables the notification-banner wait (ACCEPTED, major).
- Files: `GramAddict/core/filter.py`, `GramAddict/core/interaction.py`, `GramAddict/core/views.py`.
- Tests: pytest for `check_profile` covering public and private with `skip_if_public` and `skip_if_private` (pattern: `tests/test_blacklist_words.py`). Manual smoke: one short run with PM enabled, and check the log for private accounts.

### Batch 3 — ADB calls without `shell=True` · S–M
- Goal: argument-list `subprocess.run` for every ADB call. A password or URL with `;&$` can no longer break or leak.
- Findings: X1 `device_facade.py:240,257,344,349`; X1 `utils.py:189,207,441` plus the rest of `open_instagram*`, `check_screen_timeout`, `kill_atx_agent`, `restart_atx_agent` (ACCEPTED, downgraded to major: inputs come from local config and txt files, not remote). A shared `adb(*args)` helper in utils is justified here: it removes about 11 copies of the `-s device_id` string-building.
- Files: `GramAddict/core/device_facade.py`, `GramAddict/core/utils.py`.
- Smoke checklist (real device): locked phone unlocks with password; `is_screen_locked` and keyboard detection work; `like_from_urls` opens a URL; atx-agent restart after a crash; screen-timeout check.
